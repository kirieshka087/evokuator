# ТЯГА 24 — одностраничный лендинг эвакуатора

Готовый статический сайт без сборки. GSAP, ScrollTrigger, шрифты и изображения находятся локально в папке `assets`; блок зоны работы загружает виджет Яндекс Карт.

## Запуск

Откройте `index.html` напрямую или запустите локальный сервер из этой папки:

```powershell
python -m http.server 4173
```

Затем откройте `http://127.0.0.1:4173`.

## Перед публикацией

- замените концептуальное название «ТЯГА 24», если у компании другое имя;
- подтвердите телефон `+7 (343) 200-40-40`;
- подставьте реальные тарифы, отзывы и реквизиты компании;
- заполните все поля в квадратных скобках в подвале и `legal.html`;
- согласуйте политику конфиденциальности, согласие и cookie-текст с юристом под реальные процессы компании;
- если добавите форму, аналитику или рекламные cookie, настройте отдельное согласие до отправки/загрузки необязательных сервисов;
- проверьте необходимость уведомления Роскомнадзора об обработке персональных данных применительно к вашей организации;
- укажите рабочие ссылки на мессенджеры и реальные каналы связи.

## Структура

- `index.html` — семантическая разметка и русскоязычный контент;
- `styles.css` — дизайн-система, адаптив и reduced-motion режим;
- `legal.html` — шаблоны правовой информации с явными полями для заполнения;
- `script.js` — трёхсекундный прелоадер, сервисные попапы, мобильное меню и scroll-сцены;
- `assets/` — локальные изображения, шрифты и библиотеки анимации.
